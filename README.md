# Git Security Investigation

This repository contains documentation and tools for auditing and maintaining security in Git-based projects.

## Contents
- **SECURITY.md**: Detailed research on sensitive data management, risks of committed secrets, and best practices for protecting your codebase.
- **.gitignore**: A comprehensive template for excluding sensitive files and environment variables from version control.

## Purpose
The goal of this project is to provide a guide and a set of templates to help developers avoid common security pitfalls when working with public and private repositories on GitHub.

## How to Use
1. Review `SECURITY.md` to understand the risks and best practices.
2. Copy the `.gitignore` template to your own projects.
3. Use environment variables for local configuration and ensure they are never committed.
